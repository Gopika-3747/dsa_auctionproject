# dsa_auctionproject – Java-Based Console Auction System

This is a **Java console application** simulating an **Online Auction System**, built as part of a college Data Structures & Algorithms (DSA) project. It allows users to register, list products, place bids, and view auction winners — all through a simple command-line interface.

---

## Features

**User Registration**
- Allows new users to register with a username and password

**Product Listing**
- Sellers can list products with details like product ID, name, base price, and description

**Bidding System**
- Registered users can place bids on listed items
- Tracks highest bid and bidder in real-time

**Auction Closure**
- Displays the final winner of the auction based on the highest bid

---

## Technologies Used

**Language**: Java  
**Data Structures**:  
  - ArrayLists for storing users, products, and bids  
  - HashMaps for managing fast lookup of product/bid info
